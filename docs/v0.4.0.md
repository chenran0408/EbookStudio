# 从 v0.3.0 到 v0.4.0

本版优先缩短从第一次启动到做出一本 EPUB 的路径。对新手操作的判断来自 v0.3.0 的界面和源码走查，验收使用真实 Windows 程序与测试书稿。尚未开展新用户可用性研究。

| 优先级 | v0.3.0 的缺口 | 本版交付和验收标准 |
| --- | --- | --- |
| P0 | 从空白章开始写作前，看不到工程、插图和最终 EPUB 之间的关系。 | 首页直接打开原创中文样书《窗边的影子》。编辑、保存可编辑工程、重新打开并导出。再次打开示例可从原文重新练习。 |
| P1 | 按标题生成目录会纳入所有正文小标题，包括图表标题。 | 先按级别勾选，再选择单个标题，预览后应用。保留章节、正文和已有锚点，修改前生成检查点。 |
| P1 | 校对多期杂志时，同类 OCR 错误需要反复输入替换设置。 | 按名称保存查找文字、替换文字、正则与大小写选项，重启换书后可以载入。应用前须先看本书的预览。 |

calibre 支持保存常用搜索，Sigil 支持保存查找选项和按多级标题生成目录。下一步可考虑跨书全文检索、自定义拼写词典，以及将阅读器目录做成正文中可翻阅的目录页。 [calibre 编辑手册](https://manual.calibre-ebook.com/en/edit.html) · [calibre 书库手册](https://manual.calibre-ebook.com/en/gui.html) · [Sigil 功能表](https://sigil-ebook.com/about/) · [Sigil 保存搜索选项](https://sigil-ebook.com/blog/sigil-1.6.0-release/)

## 实测记录

- 在 Windows 11 x64 上运行便携版，从空工作区打开示例，修改中文正文，另存工程，从最近书稿重开，然后导出 EPUB。核对两级目录、跳转目标和离线 PNG。再次打开示例得到原文；遇到未保存提示时取消，原书稿的修改还在。
- 用真实窗口在一本书保存校对规则，关闭程序，再用另一本书载入规则。第一次预览前「应用替换」禁用。确认替换后保存，打开目录管理排除四级图表标题，再次保存并导出。核对六条目录的顺序、层级、两个同名标题的目标和已有锚点，正文中的图表标题和行内格式仍在。
- 在目录选择框用键盘逐项勾选并检查批量选择后的混合状态。另一次取消预览后，原工程字节和检查点数量都一致。应用后重开工程，导出第二份目录样书，逐条核对五条嵌套链接。
- 用两章中文正文检查普通文字和含捕获组的正则规则，确认无效表达式、零命中和取消均保留原稿。实测更新同名规则、删除，以及从修改前检查点恢复原稿。
- 示例、校对后导出的 EPUB 和目录筛选样书均通过 EPUBCheck 5.4.0，均为 0 错误、0 警告。Windows GUI 能显示中文正文和离线图片，便携 Agent 的 MCP 握手、随包指南和 EPUB 文件校验通过。
- 109 项自动化测试全部通过。可用下列命令运行，覆盖历史功能、示例副本、标题选择、原锚点保留以及跨书校对规则的保存、更新和删除。

~~~powershell
python -m unittest discover -s tests -v
~~~
