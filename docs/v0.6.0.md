# EbookStudio v0.6.0 实测记录

## 与 v0.5.0 的差别

| 日常操作 | v0.5.0 遇到的问题 | v0.6.0 的操作 |
| --- | --- | --- |
| 校对一个反复出现的词 | 替换预览只显示前 160 处。点击其中一行决定替换后打开哪一章，应用仍会改动全书的匹配项。 | 按章或按条目勾选，翻页时保留选择，按钮显示本次将修改的数量。 |
| 找回旧稿的一句话 | 两份检查点都可能显示同样的书名、章数和资源数。必须先恢复才能查看正文。 | 选中检查点，点击「与当前书稿比较」。在左右两栏先核对旧句和当前未保存的编辑，再决定是否恢复。 |
| 从文件夹把多本书加入书库 | 主窗口接收多个文件后会直接进入批量转换，书库窗口需要通过文件选择器登记。 | 将 EPUB 和工程拖入书库即可登记。多本书拖到主窗口时，可选择加入书库、批量转换或取消。 |

本版参考了 calibre 限定查找替换范围、比较检查点的操作，也参考了 Sigil 的多文件查找和检查点。优先级来自实际年刊复现和界面走查，未开展独立的新用户可用性研究。[calibre 编辑手册](https://manual.calibre-ebook.com/en/edit.html#search-replace) · [calibre 版本比较](https://manual.calibre-ebook.com/en/diff.html) · [Sigil 用户指南](https://sigil-ebook.com/sigil/guide/) · [Sigil 功能说明](https://sigil-ebook.com/sigil/)

优先处理逐处替换，因为一次误判就可能改动全书。其次是让用户在恢复前看到实际差异，以及让多文件拖放的去向一目了然。

## 实际书稿

- 在本机 2026 年《求是》合订本中查找“发展”，有 8,078 处命中，分布在 404 个章节。用 v0.5.0 的 Qt 窗口点中一行后，向内存副本应用替换，实际改变了全部 8,078 处。用 v0.6.0 在相同书稿上翻到第二页，只勾第 161 处，结果恰好改变一处。
- 另从整本年刊的两章中选定三处，检查点比较定位到这两章。保存可编辑工程、重开并导出后，逐章核对原文与标记。475 个章节中仅所选位置发生正文变化，474 条目录的标题、层级和目标均保留，574 项资源与输入一致。原 EPUB 的 SHA-256 保持不变。
- 输入年刊的导航文件缺少 EPUB 目录标记，EPUBCheck 5.4.0 原有一项 RSC-005 错误。工作台沿用从已有 NCX 生成导航的导出逻辑，输出年刊校验为 **0 错误、0 警告**。年刊仅在本机用于验收。
- 在 2025 年《求是》合订本的内存副本中修改一句正文，比较结果在 472 章和 777 项资源中准确定位到唯一变更的章节。另用同名章节、增删章、章节重排、格式修改和同大小但内容不同的资源验证差异分类。

## Windows 便携版

- 用原创样书《窗边的影子》的校样测试逐处替换。先只选第 161 处，再勾选另一章的两处。保存后逐章核对，前 160 处、插图、引文、强调和链接均保留。通过界面恢复检查点后找回完整原稿。校样导出的 EPUB 经 EPUBCheck 检验为 **0 错误、0 警告**。
- 在原书的一句话中把“清晨”改成“傍晚”，保持未保存状态，通过键盘打开检查点比较。左右两栏分别显示旧句与新句，返回后还能继续编辑。恢复时生成的检查点保留了新句，恢复后的书保留两级目录和原插图，导出的 EPUB 同样为 **0 错误、0 警告**。对比样式表时还核对了左右两侧的行高值 1.50 和 1.75。
- 在 Windows 11 x64 将 EPUB、可编辑工程和 TXT 从另一个程序拖入。展开「显示详情」后，三个文件名与各自可执行的操作逐项相符。取消后原来的未保存书稿和书库均保持原状。
- 拖到书库搜索框上也能登记 EPUB 和工程，窗口会说明重复项及不支持的文件。通过正文搜索找到 2025 年合订本第 1 期的目标文章，再将两份实际 EPUB 批量转换为可读 TXT。输入文件的哈希均保持一致。
- 最终源码运行 `python -m unittest discover -s tests -v`，126 项全部通过。便携 Agent 的三个 MCP 协议版本均通过工具发现、操作指南和状态检查，命令行入口可读取任务格式。
- Windows x64 ZIP 共 278,461,736 字节，已校验全部 1,958 个文件的 ZIP 完整性。SHA-256 为 `d84f173c9b443959136f4e962822484a6c0456db4ea28d03bb21467eb879a4a9`。[下载与使用说明](../README.md#下载和启动) · [Windows 发布页](https://github.com/chenran0408/EbookStudio/releases/tag/v0.6.0)
