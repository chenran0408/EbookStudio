# EbookStudio v0.7.0 实测记录

## 用实际 OCR 稿校对

样本为原创四页杂志《中文杂志 OCR 验收》的 PaddleOCR-VL-1.6 识别稿。正文含双栏、离线插图和带合并单元格的表格。原图的署名使用紧排全角斜杠，识别稿在四页共八处写成了带空格的半角斜杠。

| 顺序 | 第一步命中 | 第二步命中 | 最终文字 |
| --- | --- | --- | --- |
| 先转全角，再去掉两侧空格 | 8 | 8 | `撰稿／许禾` |
| 先清理全角符号两侧，再转全角 | 0 | 8 | `撰稿 ／ 许禾` |

正确顺序共执行 16 次替换，对应原稿中的八处署名。预览时原稿不变。应用后只有一个运行前检查点，保存工程、重新读取及导出后，四个目录目标、一幅插图、两张表和 18 个合并单元格均保留。校对稿通过 EPUBCheck，0 错误、0 警告。

## 核对两份独立文件

- **同一批扫描件的两份现成 EPUB。** 四个章节的内部文件名均不同，修订版在第一章增加了一句校对说明。比较结果正确对应四章，列出四个文件的改名、一处正文变化，以及标识符和其他出版资料的变化。
- **475 章的年刊与其校样。** 本机已有的 2026 年《求是》合订本和 v0.6.0 实测保存的修订 EPUB 共保留 574 项资源。两文件比较定位到两个章节的三处已知改字；章标题、目录及出版资料的变化单列，资源一致。两份输入 EPUB 的 SHA-256 在比较前后均未改变。年刊仅在本机用于验证。
- **用 calibre 编辑的修订版。** 用 calibre 9.18 在真实 OCR 电子书的一份副本上修改出版者。对比窗口的数据包括出版者修改、作者由空值变为“未知”，以及 calibre 加入的 JPEG 封面，原有资源保持一致。

对比适用于工作台支持的无 DRM、可重排 EPUB。改名的章节优先用相同内容或有正文印证的唯一标题对应。重打包后只剩下重复标题、又没有足够证据时，两版中未配对的章节会分别列为删除和新增。

## Windows 最终版验收

- 从空白规则列表开始，在桌面上创建、调序并保存一组规则。取消预览、退出再启动，书稿保持原样且没有额外检查点。重新载入规则组并应用后，保存的工程和导出的 EPUB 均含正确的八处署名，恢复检查点找回四章的全部原文。规则表中的 `␠` 能直观区分符号两侧的空格。
- 在有未保存校对内容时，通过两个 Windows 文件选择框打开原版和修订版。左右窗格正确显示修订版新增的句子，关闭比较后继续编辑原来的稿件。另用 calibre 添加封面的版本确认左侧提示原版缺少该图，右侧显示修订版 JPEG 缩略图。输入文件的哈希保持一致。
- 源码的 136 项自动化测试全部通过。最终 Windows 程序导出的四页杂志通过 EPUBCheck 5.4.0，0 错误、0 警告。便携 Agent 的三个受支持 MCP 协议版本及命令行入口通过回归。
