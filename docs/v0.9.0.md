# v0.9.0 功能与实测

| 优先级 | v0.8.0 的缺口 | 本版验收标准 |
| --- | --- | --- |
| P0 | 桌面能跨书找正文，Codex、WorkBuddy 和命令行无法使用同一个书库找出处。 | 从两本真实年刊各抽查三期，输入正文后找到书名、期号、文章和上下文。用返回的章号打开原文。一章有多个目录锚点时，分页仍能区分各篇文章。 |
| P0 | 一句话含有粗体、斜体、链接或上标时，整书替换和顺序规则会漏掉跨标签的命中。 | 桌面能逐项勾选。另存后只改选中的文字，保留上标、链接及目标、目录、图表。Agent 能预览、应用并导出通过 EPUBCheck 的 EPUB。 |

## 在自己的书上使用

- 对已接入的 Agent 说「把这两本 EPUB 加入我的书库，在里面找这句话，列出出处」。没加过的书要给出文件位置。Agent 会收到操作指引，用 `ebook_library_index` 登记和刷新，用 `ebook_library_search` 搜索。桌面和 Agent 使用同一个工作区就能复用索引和书库资料。[Agent 指南](../agent.md)
- 从「校对 → 整书查找替换」预览并勾选要改的位置。原句中未改动的前后缀保留原排版，改字按原位置分配给各段行内文字。加长替换会把多出的字放进最后一个受改动的样式内。链接及锚点保留，替换范围以段落、单元格、图片和换行为界。[使用说明](../README.md)

## 验收用书

- 《求是》2025 年合订本抽查第 1、13、24 期，2026 年合订本抽查第 1、11、21 期。期号和章名取自输入 EPUB 的目录，并逐章核对实际正文。年刊仅用于本机验收。
- 一份已有的双期合订工程在同一章内有「纸上春天」「河堤灯火」两篇，包含同一句话。每页返回一条结果时，两个结果分别指向原有的 `ink` 和 `lantern`，都能定位到第 1 章、第 2 期。
- 原创四页中文杂志来自先前的真实 PaddleOCR 识别。原稿里「透明鱼鳞」后接上标脚注，再接正文句号。Agent 跨过上标匹配整句并改成「透亮鱼鳞」；原文件哈希保持一致。桌面选择验收在同一份稿子第二章另外加入两处校对对照，一处有粗体和链接，另一处模拟需要原样保留的引文。



## Windows 发布包结果

- 158 项自动化测试全部通过。发布包中的桌面、Agent、共享校对及书库模块与最终测试源码一致。
- 从便携 Agent 用三个 MCP 协议版本连接，均可发现 16 个工具并读取随包指南。实际登记上述书稿后，六期抽查全部命中正确的原文章节；用命令行另起进程复用同一个索引，分页结果与 MCP 一致。抽查前后原书文件的 SHA-256 均保持一致。
- 桌面版预览出三处跨格式命中。取消后书稿不变；另一次只勾选两处，两章各改了一个字，排除的引文保留原文。另存、重开和恢复检查点均通过。导出的 EPUB 保留上标、粗体和原链接目标，导航文件、CSS、插图和两章未修改的正文与输入逐字节一致。
- Agent 直接处理原 OCR 样书，跨上标改了一处，另存可编辑书稿再导出。四项目录、一幅插图、两张表和十八个合并单元格均保留。桌面和 Agent 两份 EPUB 都通过 EPUBCheck，**0 错误、0 警告**。
- 另在 475 章年刊中校对了一句天然跨粗体和普通文字的正文，逐章比对证实只改了目标标点。该次验收仅在内存中改稿。
