# EbookStudio v0.5.0 验收记录

在 Windows 11 专业版 x64（Intel Core i5-14600K）上测试了源码和发布用的 Windows 便携版。操作步骤见[使用说明](../README.md#找一句正文制作书内目录和校对用词)。

## 跨书全文检索

从《求是》2025 年和 2026 年合订本的原目录分别选取首、中、末三期，从文章正文各取一句。在两册均已加入的书库中查询，逐次核对结果中的原文件、期号、文章标题、章节路径和上下文。

| 合订本 | 抽查期号 | 结果 |
| --- | --- | --- |
| 2025 年 | 第 1、13、24 期 | 3 句全部定位正确 |
| 2026 年 | 第 1、11、21 期 | 3 句全部定位正确 |

两册首次建索引用时 2.45 秒，重开后复用已有索引，六次索引查询耗时中位数为 4.48 毫秒。计时为本机索引层实测。两册原文件在检查前后的 SHA-256 一致。

在便携版界面中，分别从查询结果打开 2025 年第 13 期、2026 年第 11 期的对应文章。另从空书库一次加入 EPUB 与可编辑工程，验证跨行内格式的中文句子、未知期号、无命中、源文修改、文件移走和索引复用。当多个期号或多篇文章共用同一 XHTML 时，检索结果保留各自的期号和标题。打开长页中的第二篇文章，实际预览滚到 60 段之后的对应标题。在未保存提示中取消，当前书稿的修改仍在。

## 可翻阅的书内目录页

从便携版生成书内目录，保存工程，调整目录后原位更新，再从检查点恢复旧页。重复生成只保留一页，原书手写的目录内容得到保留。导出的 EPUB 有三级目录和六个链接。在宽 390 像素的离线 Chromium 中逐项点击并返回，六个目标均与预期一致，包括中文锚点和同名标题。本次使用手机宽度的浏览器视口，实体阅读设备未参与测试。

另用一份已有阅读器目录的 EPUB 做往返测试。原目录有三级、六个小节锚点，全部共用同一章。用最终 EXE 打开原刊，生成书内目录，另存为可编辑工程并导出。原文件哈希保持一致，导出书保留全部原目录项的标题、层级、路径和锚点。在 390 像素宽的离线浏览器里逐项点击新生成的六个链接，都到达原有小节。

## 自定义拼写词典

在第一本书中认可英文专名、设置中文错词，退出工作台并打开另一本书。专名和错词设置仍然生效。检查窗口显示命中章节及上下文，可跳转，也可预览后修订。实际将英文 `recieve` 改为 `receive`，将「己经」改为「已经」，核对保存的工程和导出的 EPUB，斜体、链接和原锚点均保留。移除专名后再次重启，工作台重新报出该词。基础词典为美式英语，中文按用户登记的错词检查。[词典来源与许可证](../THIRD_PARTY.md)
